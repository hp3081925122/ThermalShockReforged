# Thermal Shock Reforged 剧情索引（精简版）

> 本文只保留能说明世界观、人物、事件和未解线索的文本。物品名称、UI 按钮、配方、战斗属性、功能提示、相机图鉴、生物百科、技术 ID 和迁移统计已移除。

## 一、故事主线

### 1. 进入无尽花园

- 玩家从主世界使用界域基石，在平放的 3×3 黑曜石平台上进入无尽花园（Loqendia）。
- 无尽花园是一个经历过冰雪灾难、感染和文明崩坏的异世界，虫族遗迹、涌能塔和旧城市构成主要探索背景。
- 神秘资助者通过广播赠送或引导玩家取得界域基石，并要求玩家前往指定坐标；其身份尚未揭示。

### 2. 旧文明与光能灾难

- 结构书提到，旧王复苏后，士兵和人造金属巨人拆除了维系城市的涌能塔，把塔心带入黑暗高塔并拆解。
- 塔心蕴含来自太阳的巨大能量，Phoenum 曾将其封存。书中还提到 Phoenum、Zenillia、Ferraq 和 Uuril 花园等旧文明遗迹。
- 叙述者承认自己无法理解光传达的信息，曾以错误的解释遮蔽真相，并让页岩泉镇永远安全、也永远“盲目”。

### 3. 暴雪计划与层云部门

- 暴雪计划在地下和水边建立基地，利用凝胶储能块研发激光枪、电击拳套等技术。
- 层云部门原本负责卫星和气象气球，后来被迫研发冰蚀无人机、战车和“千灵”等军事项目。
- 工虫联合会因工作压力和军事化方向抗议、停工。录音暗示，所谓“晋升”还包括外科手术和脑部改造。
- 机械师、层云合金和病毒石任务把玩家逐步引向暴雪圣所、档案馆及其更深层的政治问题。

### 4. 感染与亵渎

- 尤妮特描述感染者会死亡、吸入孢子，或被感染物占据身体；有些感染者只剩白骨。
- 礼宾使认为感染与失衡能量有关，并把亵渎者及其信徒视为文明自毁的表现。
- 亵渎任务链要求玩家接受源初之血委托，深入秽血浴场，击败三名先驱，取得腐化核心碎片，再提取源初之血并取得万灵药。
- 该任务链对应“亵渎 其一”至“亵渎 其四”，是目前最完整的剧情线。

### 5. 花园深处与失败的远征

- 一支远征队曾挖进巨大的蒲公英花园，发现从未记录过的虫形植物；这与洞穴绽花生态有关。
- 另一支队伍尝试进入蜂巢般的大型结构，却在第一道墙前损失人员并撤退，说明花园深处仍有未解决的威胁。
- 摄影师委托要求玩家记录冰川群系中的洞穴绽花，表明这些生物和花田是当地持续关注的谜团。

## 二、主要阵营与人物

### 页岩泉镇

- 尤妮特和姐姐从合唱城迁来。她提到“那件事”后游客减少，但没有说明具体事件。
- 页岩泉镇受到旧文明遗迹和光能封印保护，却也因此长期处于信息闭塞状态。

### 暴雪计划与层云部门

- 暴雪计划负责能量、武器和生物机械项目。
- 层云部门的录音表现出普通工虫对军事化、过劳和强制改造的反抗。
- 机械师相关任务揭示了不安同盟、层云合金和病毒石之间的联系。

### 礼宾使与亵渎者

- 礼宾使负责发布源初之血任务，并以秩序和文明存续的名义解释感染问题。
- 亵渎者及其先驱控制着秽血浴场，腐化核心碎片是这条线的关键证据。

### 神秘资助者

- 对方通过广播发送礼物、坐标和暗示性指令。
- 文本没有确认其真实身份，只能确认对方在主动引导玩家探索无尽花园。

## 三、关键结构书

### `cathedral.nbt`

以宗教式语言歌颂光，并把永恒的寒冷与空虚包装成信仰的一部分。它体现了圣所意识形态，而不是单纯的环境描述。

### `shalespring_rubicon.nbt`

叙述者回忆 Phoenum、Zenillia、Ferraq 和 Uuril 花园，承认自己曾经无法理解光，最终以“祝福”让页岩泉镇安全却失去真相。

### `snowtower.nbt`

记录旧王复苏、士兵和金属巨人拆塔、塔心被带入黑暗高塔并拆解的过程；同时暗示塔心拥有来自太阳的巨大能量，并提出“钥匙”与隐藏秘密的关系。

### `lavender_palace.nbt`

主要是作者创作谈，介绍模组的开发历程、灵感和风格变化，不属于游戏内剧情，因此不再收录。

## 四、全息录音线索

- **录音 1**：瞭望前哨正在试验能量回收技术，传统研究人员对祭坛和“死去的阳光”感到疑惑。
- **录音 2**：员工抱怨新主管和长期取消的休息，暗示管理层已经出现严重问题。
- **录音 3**：高层催促层云部门交付实验原型，并同时要求推进生物机械项目。
- **录音 4**：Qo 代表工虫联合会，公开质疑层云部门被迫转向军事化。
- **录音 5**：主管要求在极短时间内完成战车原型，联合会因此停止工作。
- **录音 6**：寇成为百周期最佳员工后将接受“晋升”手术，录音明确暗示脑部改造。
- **录音 7**：远征队发现巨大的蒲公英花园和未知虫形植物。
- **录音 8**：蜂巢结构远征失败，队伍损失人员并撤退。
- **录音 9**：一段尚未解码的密码化报告，提到项目、人员和“死亡”相关词汇，是当前最重要的未解文本之一。

## 五、任务与进度中的剧情节点

- **界域基石 / 无尽花园**：玩家获得进入异世界的入口，并开始接触当地遗迹与人物。
- **守护者与圣所**：玩家需要取得病毒石并让守护者涌能塔超载，以关闭圣所保护力场。
- **亵渎 其一至其四**：从源初之血委托开始，经过秽血浴场、先驱、腐化核心碎片和万灵药。
- **层云合金与不安同盟**：把暴雪计划、机械师和强制研发线索连接起来。
- **Beta v07 / 未完待续**：进度文本明确表示主线尚未结束。
