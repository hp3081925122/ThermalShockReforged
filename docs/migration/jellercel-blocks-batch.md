# 第76批：动画Jellercel装饰与大型整体方块

先核原JellercelBlock、LargeJellercelBlock、LargeJellercellCollisionBlock、三个放置/拆除过程、方块实体及物品/方块渲染。小型保0.1～15.9像素碰撞，硬度0.5/抗爆1、BASEDRUM；大型保0.1～31.9像素完整体积、硬度2/抗爆1、活塞阻挡及七个占位格。两者SLIME_BLOCK音、亮度10、透明/自发光属性、含水、动画状态0～1、原完整模型/动画，分别复用9格/六侧物品能力。默认地图颜色补粉色，保持透明性；占位格仍不可见。原物品JSON实际是item/generated图标；即使Java注册了Geo渲染器，也不能推断物品已调用三维显示。保留两图标与已配置Geo资源，不擅自更改未被item模型引用的displaysettings父级。

原生物接触玩家是CACTUS伤害，装饰方块碰撞则为1点无归属LIGHTNING_BOLT，不能混淆。小型/大型核心保entityInside，七占位保entityInside与stepOn；仅服务端实际结算伤害，不添加扫描、额外攻击CD或雷电实体。

已确认旧大型放置用canOcclude判定空间，会覆盖非遮挡容器/植物且对核心位置错误dropResources；拆除不检查邻位身份，可能删除后来换入的任意方块。替换为放置前验证全部七格的可替换性、边界、已加载区块和方块实体，原子验证后填充；占位状态保存相对核心的编号，清理时同时核方块ID和归属，只还原属于本体的占位格。小范围直接查询，不使用全局队列/每tick扫描。兼容原结构占位无编号的有界局部核心查找。

状态0/1变化不重新生成占位，移除核心时只清理自身部件；敲任一占位拆除同一个核心且至多一份核心掉落，创造模式不掉落；含水各格分别保留和恢复，不把水源静默删掉。邻位已被替换则保持替换内容。爆炸、命令替换和正常采集共用整体清理，避免重复掉落和反向递归。新诊断日志使用英文debug，仅失败放置记录。

占位也阻挡活塞，避免单独推出后残留体积。跨区块拆除不强制加载未加载的邻区块；占位通过原版随机更新做有界归属检查，在相关核心区块已加载且确认核心不存在后还原流体，相关区块未加载则不误删。不增加每tick扫描或7个额外方块实体。该极端边界的清理具有随机更新等待时间，最终服务端验收必须覆盖。

本批同时恢复原两条拆解配方（小型→4 Cell，大型→8 Cell）、占位空掉落表，并核原创意入口、粒子模型与物品显示资源。原ThermalShockModTabs只列小型Jellercel，大型不在创意页，目标保持这一差别。自然结构及其feature在完整世界生成链单独核对，不以这两个方块注册冒充世界生成已全部闭合。统一与第75批编译/静态验证；游戏最终验收待整模组完成。
