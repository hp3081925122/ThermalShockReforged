# 第143批：最终主线服务端完整功能验收

本批使用当前主线最终整合源码和资源，接入既有 D 盘隔离 GameTest 工程，重新验证服务端行为。历史 `docs/testing/early-tests` 累计结果来自旧快照，只作为测试资产和回归背景，不直接作为当前主线通过证明。

验收分三路：战斗/死亡/维度边界、武器/投射物/机器边界、早期内容/世界 NPC/Atlas/结构交互。每路使用独立工程、独立运行目录和 `max-workers=1`，测试辅助文件与生产源码分离。先固定当前主线输入并编译测试源码，再执行 `runGameTestServer`；保存每路日志、退出码、GameTest结果和当前主线 JAR SHA。

本批只记录服务端结果，不启动客户端或 Render Preview，不修改用户测试目录、不把测试辅助文件合入迁移提交。失败项按真实产品缺陷、测试夹具误设、环境/缓存问题分类；只有当前主线源码在真实服务端入口下复现的失败才进入生产修复批次。
