# 两种提示球的原范围与跨阶高度

来源为07.9原JAR的StopperOrbEntity、MoverOrbEntity及两个tick过程。两过程均以坐标点构造AABB再inflate(0.5)，按距原坐标排序后，只对未潜行/未疾跑玩家造成5点无归属INDIRECT_MAGIC，分别发送原5颗BLUE_X_BLAST/SMALL_FLAME。实体本身尺寸为0.6×1.8，不是伤害判定盒的组成部分；两实体构造器均setMaxUpStep(0)。

第122批基线的OrbEntityBase错误使用getBoundingBox().inflate(0.5)，使判定盒相对原点横向由±0.5扩大为±0.8，竖向由[-0.5,+0.5]扩大为[-0.5,+2.3]。共享属性没有显式STEP_HEIGHT=0，落入目标原生默认值。本批恢复原点方盒、原距离顺序和0跨阶高度，增加仅有候选玩家时的英文debug以供最终运行核查。

潜行/疾跑条件、5点伤害类型、粒子数量/范围/速度、朝向速度0.5、100tick保存寿命及两球独立注册保持原实现。不是伤害平衡调整；终段仍先处理玩家后移除。静态边界检查与编译分别记录，尚未运行游戏，不声明声画或真实命中验收通过。

后续客户端检查需覆盖水平0.5边缘、球体上方0.5与1.8高度区域、双球潜行/疾跑条件、多玩家距离顺序、寿命末tick以及卸载重载剩余寿命。
