## 四、需要注意的特殊机制

1. **矿物二选一**：红宝石与血石、孔雀石与铋，每个世界只会各生成其中一种，在首次放置寰宇图鉴时随机决定；未生成的一方可用转化仪由另一方转化。相关条目（矿石、粗矿、宝石、碎片、晶簇、露头）已标注「世界矿物选择」，正文务必写明。
2. **能量**：制造机配方均消耗深寒能量；离心机可在深寒能量与热能能量之间转化。
3. **NPC 交易**：礼宾使、Ly、叛逃机械师、花艺师、摄影师、低语者提供交易，部分交易额外消耗经验等级，已在对应条目中写出。
4. **提取机**：部分物品放入提取机会按概率多次判定产出材料，或直接给予经验。
